# Navegacion

## Flujo principal

```text
Landing -> Sign up / Login -> Payment -> Quiz -> Dashboard
```

## Secciones del producto

- Onboarding
- Treatment Profile
- Dashboard
- Dose Tracker
- Symptom Monitor
- Symptom Guides
- Nutrition
- Anti Rebound
- Alerts
- Reports
- Subscription
- Settings

## Regla de experiencia

- El dashboard cambia segun contexto.
- El orden de tarjetas cambia segun prioridad.
- Los mensajes cambian segun idioma, sintomas y etapa.
- La navegacion debe favorecer accion rapida, no exploracion excesiva.

## Protecciones

- Ruta protegida para producto.
- Ruta de suscripcion para acceso inicial.
- Ruta de quiz para construir perfil.
- Ruta de reportes para seguimiento medico.
