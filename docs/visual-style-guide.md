# Visual Style Guide

Referencia visual extraida de la interfaz compartida.
Este documento ignora estructura, texto y funcionalidad; solo fija el lenguaje grafico.

## Direccion General

- Aesthetic: clean medical, corporate, calm, reliable.
- Sensation: claridad clinica con un toque humano y acogedor.
- Mood: ordenado, accesible, sin ruido visual.
- Priority: legibilidad y confianza por encima de ornamento.

## Palette

- Base clara con fondo casi blanco y tonos frios muy suaves.
- Primary: teal profundo para acciones principales y estados activos.
- Accent: naranja/coral para CTA de alto contraste y elementos de alerta.
- Semantic support: verde-azulado para progreso, ambar para advertencias, rojo solo para error real.
- Neutrals: grises frios para bordes, texto secundario y superficies de apoyo.

## Surfaces

- Fondo principal uniforme y luminoso.
- Cards blancas o apenas tintadas.
- Jerarquia mediante contraste tonal y bordes, no mediante sombras pesadas.
- Capas sutiles con bloques de color suave para estados y mensajes.

## Typography

- Familia principal: Inter.
- Titulares: pesados, compactos, con tracking ligero negativo.
- Cuerpo: amplio, legible, con line-height generosa.
- Labels: pequenas, limpias, en mayusculas o estilo caps cuando se necesita jerarquia.

## Shapes

- Cards: radius medio-suave, alrededor de 12px.
- Inputs y botones: radius algo menor, alrededor de 8px.
- Badges y pills: completamente redondeados.
- Bordes visibles y consistentes, generalmente de 1px.

## Layout

- Mobile-first.
- Mucho aire entre bloques.
- Secciones apiladas verticalmente con ritmo claro.
- Grid de tarjetas en 2 columnas para acciones rapidas.
- Barra inferior fija para navegacion primaria.

## Components

- Header superior simple con marca y estado.
- Title area grande y directa.
- Banner de estado destacado cerca del inicio.
- Cards con contenido corto, escaneable y accionable.
- CTA principal grande, lleno de color y de ancho completo.
- Pills para estados, categorias o recomendaciones.
- Navegacion inferior con icono + label.

## Depth & Effects

- Casi sin sombras.
- Sin degradados decorativos.
- Sin glassmorphism.
- Estados activos por color, borde o relleno, no por brillo.

## Iconography

- Iconos outline, de trazo limpio.
- Peso medio, consistentes y funcionales.
- Uso pragmatico, no ornamental.

## Interaction Feel

- Transiciones discretas.
- Hover y active states muy suaves.
- El foco esta en claridad y confianza, no en microinteracciones llamativas.

## Implementation Notes

- Mantener el sistema visual en modo claro como base.
- Reservar el naranja para CTA y momentos de mayor urgencia.
- Usar teal como identidad principal de producto.
- Mantener consistencia en espaciado, radios y bordes para que todo se sienta parte del mismo sistema.
